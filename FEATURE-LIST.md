# 🎓 KEY DECISIONS MADE

## 1. Profile Photos
- **Max photos:** 10 (industry standard, enough variety)
- **Moderation:** Auto-approve + admin post-moderation queue (faster UX)
- **No face photo:** Allow with persistent warning popup (inclusive approach)

## 2. Contact Information
- **Fields:** Phone + Email (WhatsApp number = same as phone)
- **Visibility:** User-controlled privacy: Mutual interest / Premium users / Premium with mutual interest
- **Default:** Hidden until mutual interest (builds engagement)

## 3. Horoscope
- **Non-Hindus:** Can skip completely (not applicable)
- **Format:** Both upload (PDF/Image) + manual entry (Rashi, Nakshatra, time, place)
- **Matching:** Side-by-side view in Phase 1, Guna scoring in Phase 2
- **Astrologer:** Phase 3+ (paid consultation marketplace)

## 4. Chat System
- **Free users:** Chat ONLY after mutual match (both accepted interest) - aligns with Shaadi.com model
- **Premium users:** Can message anyone anytime (premium perk)
- **Group chat:** NOT implementing (too complex, cultural concerns)

## 5. Verification
- **Phase 1:** Phone + Email auto-verification (fast onboarding)
- **Phase 2:** Government ID + Video verification (builds trust)
- **Approach:** Free feature (trust-building, not monetization)

## 6. Income Field
- **Mandatory:** Yes (with "Prefer not to say" + "Not earning" options)
- **Format:** Ranges (better privacy than exact amounts)
- **Ranges:** ₹2-5L, ₹5-10L, ₹10-15L, etc. (11 ranges total)

## 7. Family Details
- **Family Type:** Joint / Nuclear / Open to Both
- **Family Values:** Traditional / Moderate / Liberal
- **Both mandatory** (important matching criteria in Indian context)

## 8. Search Filters
- **Count:** 30+ comprehensive filters (more = better matching)
- **Performance:** Indexed DB queries + Redis caching
- **Save searches:** Up to 10 saved searches per user

## 9. Interest System
- **Resend cooldown:** 30 days after decline (prevent spam)
- **Message limit:** 500 characters (enough to personalize)
- **Expiry:** 60 days if no response (keep queue clean)

## 10. Premium Expiry
- **Approach:** Soft lock (can read old data, can't access new)
- **Old messages:** Readable (user retains value)
- **Old contacts:** Readable (user retains value)
- **Grace period:** 7 days with renewal prompts (maximize conversions)

## 11. Profile Boost
- **Phase:** Moved to Phase 2 (not critical for MVP)
- **Price:** ₹500 for 7 days (affordable, recurring revenue)
- **Stacking:** Extends by 7 days if already active (simple logic)

## 12. Block Users
- **Visibility:** Bidirectional invisibility (strong privacy)
- **Mutual block:** If A blocks B, B can't see A (prevents harassment)
